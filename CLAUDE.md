# Agent instructions

Rules for any AI agent working in this repo.

- Keep code comments to an absolute minimum. Code should be self-descriptive —
  prefer clear naming and structure over explaining what the code does.
- Write in French: table/column/view names, code identifiers, comments, and
  string values (e.g. enum-like fields such as a type column) are all in
  French. SQL/programming keywords and library/API calls stay as-is — only
  the vocabulary we choose is French.
